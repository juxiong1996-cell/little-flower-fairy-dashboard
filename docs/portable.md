# Windows 便携发布包

发布包自带 Node.js。收件人解压整个压缩包，双击“启动签到台.cmd”，签到台会自动打开。需要 Windows 10/11，以及已有的 Microsoft Edge 或 Google Chrome。包里不包含浏览器；程序使用现有浏览器运行官方游戏。

不需要安装 Node.js、npm、Python、.NET Framework 或中文文字识别组件。代码中的登录导航使用 JavaScript，查询、签到和领奖使用官方游戏连接。

启动窗口需要保留，关闭窗口或关机后定时签到停止。重复双击启动文件会打开已经运行的签到台。启动器只会复用经过本机实例标记确认的服务；端口被其他程序占用时会说明原因。

## 制作压缩包

准备 Windows 64 位 Node.js 22 或更新版本的 `node.exe` 和同版本官方完整 `LICENSE`。如运行时还导入额外的第三方 DLL，打包器会拒绝生成缺少运行库的包；当前本机 Node.js 24 为单文件静态运行时。

```powershell
node scripts/build-portable.mjs --node-license "完整的Node许可证路径"
```

默认产生 `dist/小花仙签到台/` 和 `dist/小花仙签到台.zip`。发送 zip 即可。目录已存在时不会覆盖；请使用新的输出目录，例如：

```powershell
node scripts/build-portable.mjs --node "C:\node\node.exe" --node-license "C:\node\LICENSE" --out "D:\发布\小花仙签到台-新版"
```

仅生成文件夹、暂不压缩时加 `--no-zip`。压缩使用 Node.js 自带模块完成，不需要 PowerShell 压缩组件或其他压缩软件。

打包器只收集服务端和启动器实际导入的项目模块、三个网页文件、启动脚本，以及项目的 `README.md`、`LICENSE`，再加入 Node.js、Node.js 许可证和使用说明。不会复制 `.local`、`.git`、开发截图、测试文件、账号资料或电脑上的环境配置。

源码和便携包均仅供个人学习和非商业研究，禁止商业使用、收费销售、收费分发或用于商业服务。分享时须保留项目许可和第三方许可，详见根目录 `LICENSE`。

账号的登录资料和定时设置仍保存在每个使用者自己的 `%LOCALAPPDATA%\LittleFlowerFairyLogin` 中。程序文件可以移动；不要分享该账号资料目录。

## 可选启动配置

`FLOWER_WEB_PORT` 可指定网页端口（默认 4876；0 表示自动选取空闲端口）。使用自动端口时，再次启动仍会先验证并复用已有实例。`FLOWER_NO_OPEN=1` 或启动器参数 `--no-open` 用于测试，启动后不自动打开浏览器。

`FLOWER_DATA_DIR` 可指定独立的账号和设置目录。进行发布验收时应使用新建的空目录，避免读取制作者的真实账号或触发已有定时任务。

`FLOWER_ACTIVITY_ADAPTER` 可指定本机自定义活动接入模块，与 `node src/app/server.mjs` 的行为一致；不设置时使用内置官方接入。外部接入模块不会自动放入发布包。
