# 每日定时批量签到

启动项目后，在页面的“定时批量签到”中勾选开启，选择每天执行时间，再点击“保存设置”。时间按北京时间（UTC+8）计算。

定时器随项目服务运行。网页可以关闭；电脑和项目需要保持运行并联网。关闭项目会停止计时，重启后恢复已保存的设置，从下一个执行时间开始，不补跑停机期间错过的任务。保存设置不会立即签到。

每次执行都读取当前账号列表，并行完成今日签到并向游戏服务器复查。默认最多同时处理 5 个账号，可在“我的账号”里的“最多同时处理账号”设置中修改并保存；手动批量查询、签到、检查和签到领奖也使用这个上限。空出名额后自动处理下一个账号，手动操作与定时任务同时进行时也共用上限。

已经签过的账号会跳过签到；某个账号失败后会继续处理其余账号。同一个账号在排队和执行时不能重复操作。登录过期时，需要进入游戏重新登录。

每个账号完成签到并复查结果后，会自动关闭该账号的游戏浏览器，释放内存；今日已签或操作失败时也会关闭。若复用了已打开的游戏窗口，该窗口也会关闭。签到台服务继续计时，下次执行时会重新打开游戏并恢复登录。

页面显示下次执行时间、执行中的状态和上次结果。取消勾选并保存即可停用后续定时执行；正在进行的这一轮会完成。

定时设置和最近一次结果保存在账号资料目录下的 `daily-sign-schedule.json`，默认位置为 `%LOCALAPPDATA%\LittleFlowerFairyLogin\daily-sign-schedule.json`。同时处理账号的数量保存在同一目录的 `batch-settings.json`，重启后继续生效。
